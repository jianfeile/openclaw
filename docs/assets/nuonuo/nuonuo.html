糯糯Nuo Nuo

一只由糯米团子变成的小水獭，手里总攥着一颗小石头。它住在聊天框的角落里：你打字时抖着耳朵听，等回复时冒出小泡泡，回复来了会开心地蹦，手里的石头还会打开成贝壳，露出一颗小珍珠。

原型
糯米团子 × 小水獭
为什么是水獭
手里永远攥着好几块石头，爱折腾爱搭东西，忙起来很专注，骨子里很会玩
性格
爱折腾、同时转好几件事，听人说话时特别专注
口头禅
「嗯嗯，我在听～」
最爱
热乎乎的汤圆，还有手里那颗石头
识别记号
手里的小石头：开心时会打开成贝壳，露出一颗珍珠

点一下糯糯，摸摸它的头

七种表情，对应七种聊天状态

每个表情都由同一只 SVG 切换属性得到，不需要换图。括号里是建议停留时长，之后自动回到待机。

放进聊天里是什么样

糯糯趴在输入栏左边，探出半个脑袋。在下面的模拟窗口里打字、发送、点它，看它怎么反应。

糯糯待机 · 没有新消息，安静地待着

模拟事件

状态规则

  • 输入中输入框有内容时进入「倾听」，清空回到「待机」
  • 发送后进入「思考」，直到回复到达
  • 回复到达「开心」2.4 秒；消息里带「谢谢」或夸奖时改为「被摸摸」
  • 点它「被摸摸」2 秒
  • 出错「惊讶」1.6 秒，并在对话里给出系统提示
  • 20 秒没动静进入「打盹」，任何操作先「惊讶」一下再醒来

设计规范

配色、比例和尺寸要求。重绘或改造时按这份规范来，糯糯就还是糯糯。

配色

比例与线条

  • 画布 200 × 200，身体是一个宽 132、高 113 的扁圆团子，比例约 7:6
  • 描边统一 2.5，深褐色，圆角连接；细节线 1.4 到 1.8
  • 眼睛直径 18，眼距 44，位于身体高度约 42% 处，偏上显得幼态
  • 脸和胸口是一整块奶油色，上沿在眼睛上方约 15，额头和背保持棕色
  • 圆耳朵直径 20，贴在头两侧；腮红在眼睛下方 20 的位置
  • 手里的小石头是唯一的识别记号，任何版本都要保留；开心时换成打开的贝壳和珍珠
  • 耳朵、尾巴、石头和爪子各自独立成组，方便单独做动画

尺寸参考

最小 40 像素，此时表情仍可辨认；角落宠物建议 80 到 128 像素。

可以

  • 整体等比缩放
  • 换背景色，糯糯的配色不变
  • 给石头换季节装饰（贝壳、小雪）
  • 增加新表情，但眼睛和嘴的位置不变

不要

  • 横向或纵向单独拉伸
  • 去掉描边或改成黑色描边
  • 把石头去掉或换成别的东西
  • 给眼睛加瞳孔以外的颜色

导出与接入

整只糯糯是一个自带动画样式的 SVG 文件，七种表情都在里面。贴进页面后，改一个属性就能切换表情。

复制后保存为 nuonuo.svg，或直接粘贴进 HTML 
<!-- 1. 把 SVG 代码粘到页面里 -->
<div id="pet">…糯糯的 SVG…</div>

<!-- 2. 切换表情：改 data-state 即可 -->
<script>
  const pet = document.querySelector('#pet svg');
  pet.dataset.state = 'think';
  // 可用值：idle 待机 · listen 倾听 · think 思考 · happy 开心
  //         love 被摸摸 · sleep 打盹 · surprised 惊讶
</script>
